
## [2026-05-29 10:26:12]

### 🚀 Added
- **Persistence:** Сохранение истории ввода в отдельном файле рядом с исполняемым файлом.
- **Analytics:** Глобальная статистика использования токенов для всех сессий.
- **Session Management:** 
    - Команда `/history [ID]` для загрузки прошлых сессий.
    - CLI-ключ `--history [ID]` для запуска программы с конкретной сессией.
- **CLI Extensions:**
    - Ключ `--input [file]` для считывания запроса из текстового файла.
    - Ключ `--output [text]` для получения ответа в консоли без входа в интерактивный режим.
- **New Commands:**
    - `/model [name] --provider [provider]` — одновременная смена модели и провайдера.
    - `/model [name] --default` — установка модели по умолчанию.
    - `/new --clear` — создание нового чата с очисткой экрана.
- **UX Improvements:**
    - Автозаполнение команд и истории ввода.
    - Отображение столбца затраченных токенов в таблице команды `/history`.

### 🛠 Changed
- **Input:** Теперь отправка текста осуществляется сочетанием клавиш `Ctrl+Enter`.
- **Streaming:** Исправлено отображение текста при стриминге ответа (теперь выводится весь текст).
- **UI/UX:** 
    - Ограничено отображение многострочного текста из буфера обмена (макс. 30 строк).
    - Обновлен общий интерфейс программы.
