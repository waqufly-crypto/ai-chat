# 🤖 AI Chat — терминальный чат-клиент для LLM

Минималистичный, но мощный CLI-клиент для общения с LLM через любой **OpenAI-совместимый API** (OpenAI, DeepSeek, локальные модели и
т.д.). Стриминг ответов в реальном времени, поддержка thinking-моделей, переключаемый Markdown-рендеринг, персистентная история, учёт
токенов и стоимости.

```
╭───────────────────────────────────────────────────────────────────────────╮
│ 🤖 AI Chat │ Модель: GPT-4o                                                 │
│ Введите /help для списка команд                                             │
╰───────────────────────────────────────────────────────────────────────────╯
Вы › Привет
─────────────────────────────────────────────────────────────────────────────
🤖 GPT-4o

Привет! 👋 Чем могу помочь?

⏱ Токены: ↑50 ↓21 │ 💰 0.0009₽ │ ⏳ 3.5с
─────────────────────────────────────────────────────────────────────────────
Вы ›
```

---

## 📦 Требования

- **Python 3.10+**
- Зависимости:
  - `openai >= 1.0`
  - `rich`
  - `prompt_toolkit`

## 🚀 Установка

```bash
pip install openai rich prompt_toolkit
```

Скачайте `main.py` в любой каталог. При первом запуске рядом будет создан `config.json`.

## ⚙️ Настройка

При первом запуске:

```bash
python main.py
```

Программа создаст файл `config.json` рядом с `main.py` и завершится с сообщением:

```
Конфиг создан: /path/to/config.json. Укажите api_key и запустите снова.
```

Откройте `config.json` и укажите ваш `api_key`.

### Структура config.json

```json
{
  "api_key": "sk-...",
  "api_base": "https://api.openai.com/v1",
  "default_model": "gpt-4o",
  "system_prompt": "Ты полезный ассистент.",
  "render_markdown": false,
  "generation": {
    "temperature": 0.7,
    "top_p": 1.0,
    "max_tokens": 4096
  },
  "models": [
    {
      "id": "gpt-4o",
      "name": "GPT-4o",
      "context_window": 128000,
      "input_price_per_1m_tokens_rub": 150.0,
      "output_price_per_1m_tokens_rub": 600.0
    },
    {
      "id": "deepseek-reasoner",
      "name": "DeepSeek R1",
      "context_window": 65536,
      "supports_thinking": true,
      "input_price_per_1m_tokens_rub": 3.0,
      "output_price_per_1m_tokens_rub": 15.0
    }
  ]
}
```

### Описание полей

| Поле | Обязательное | Назначение |
|---|---|---|
| `api_key` | ✅ | API-ключ провайдера |
| `api_base` | ✅ | URL OpenAI-совместимого API |
| `default_model` | ✅ | `id` модели по умолчанию |
| `system_prompt` | — | Системный промпт (дефолт: `"Ты полезный ассистент."`) |
| `render_markdown` | — | Включить markdown-рендеринг по умолчанию (дефолт: `false`) |
| `generation.temperature` | — | Температура (дефолт: `0.7`) |
| `generation.top_p` | — | top_p (дефолт: `1.0`) |
| `generation.max_tokens` | — | Лимит токенов ответа (дефолт: `4096`) |
| `models` | — | Список моделей для меню и расчёта стоимости (дефолт: `[]`) |

### Поля модели (`models[]`)

| Поле | Обязательное | Дефолт |
|---|---|---|
| `id` | ✅ | — |
| `name` | — | равно `id` |
| `context_window` | — | `128000` |
| `supports_thinking` | — | `false` |
| `input_price_per_1m_tokens_rub` | — | цена не считается |
| `output_price_per_1m_tokens_rub` | — | цена не считается |

> Если модель из `default_model` отсутствует в `models` — чат работает, но стоимость не рассчитывается (показывается `—`).

## ▶️ Запуск

```bash
python main.py
```

### CLI-флаги

| Флаг | Описание |
|---|---|
| `--markdown`, `-m` | Принудительно включить markdown-режим на старте |
| `--no-markdown` | Принудительно выключить markdown |
| `--debug` | Полный traceback ошибок в stderr |
| `--history <session_id>` | Открыть сохранённую сессию как контекст. Пример: `--history 20260527_092354` |
| `--input <file.txt>` | Считать содержимое файла как первый запрос пользователя |
| `--output "<текст>"` | **Неинтерактивный режим**: отправить запрос, вывести ответ в stdout и выйти (для пайпов/скриптов) |

Примеры:

```bash
# Markdown с самого старта
python main.py -m

# Продолжить старую сессию
python main.py --history 20260527_092354

# Отправить файл как запрос и продолжить чат
python main.py --input prompt.txt

# Неинтерактивно (для скриптов)
python main.py --output "Сколько будет 2+2?"
echo "Объясни рекурсию" | xargs -0 -I{} python main.py --output "{}"
```

## 💬 Использование

Промпт `Вы › ` ожидает ваш ввод. Текущая модель показана в верхней панели.

### Таблица команд

| Команда | Описание |
|---|---|
| `/new` | Сохранить текущую сессию и начать новый разговор |
| `/new --clear` | То же + очистка экрана |
| `/history` | Таблица последних 20 сессий; ввод номера → загрузка |
| `/history all` | Все сессии |
| `/history <session_id>` | Загрузить конкретную сессию по имени файла |
| `/model` | Пронумерованный список моделей; ввод номера → переключение |
| `/model <имя или №>` | Быстрое переключение (поиск по id/name, частичное совпадение) |
| `/model <модель> --default` | Переключить и записать `default_model` в `config.json` |
| `/model <модель> --provider <p>` | Переключить модель и провайдера |
| `/markdown` | Показать состояние markdown-рендеринга |
| `/markdown on` / `/md on` | Включить markdown |
| `/markdown off` / `/md off` | Выключить markdown |
| `/markdown toggle` / `/md` | Переключить режим |
| `/file <путь>` | Отправить содержимое текстового файла (с превью и подтверждением) |
| `/clear` | Очистить экран (контекст сохраняется) |
| `/usage` | Статистика текущей сессии и за всё время |
| `/help` | Справка |
| `/exit` | Сохранить сессию и выйти |

Неизвестная команда (начинающаяся с `/`) **не отправляется в API** — выводится подсказка.

Примеры:

```
/model deepseek --default      # сделать DeepSeek моделью по умолчанию
/model 2 --provider openrouter # переключить модель №2 и провайдера
/new --clear                   # новый разговор с чистым экраном
/history 20260527_104451       # загрузить конкретную сессию
```

## 🎨 Режимы отображения ответа

Поддерживаются **два режима**:

1. **Plain text** (по умолчанию) — текст выводится «как есть». Символы Markdown (`` ` ``, `#`, `-`, `\`) не интерпретируются. Вы видите
ровно то, что вернул API.
2. **Markdown** — рендеринг через `rich.markdown.Markdown`: таблицы, списки, блоки кода, заголовки.

Переключение **на лету**:

```
/md on      # включить
/md off     # выключить
/md         # переключить
/markdown   # показать текущее состояние
```

> Режим — runtime-флаг, **не сохраняется** в файл сессии. Уже выведенные ответы не перерисовываются — изменения применяются к следующим.

## ⌨️ Многострочный ввод и автозавершение

- **Enter** — перевод строки (новая строка внутри сообщения)
- **Ctrl+Enter** — отправка сообщения
- **↑ / ↓** — навигация по персистентной истории ввода
- **Ctrl+V / Shift+Insert** — вставка из буфера, в т.ч. многострочная
- При вставке очень длинного текста в предпросмотре показывается не более **30 строк** (`… ещё N строк`), но в сообщение уходит **полный
текст**
- **Автозавершение**:
  - команд (`/new`, `/model`, `/markdown`, …) и их аргументов (`on/off/toggle`, `--default`, `--provider`, `--clear`, `all`)
  - истории ввода (auto-suggest из предыдущих запросов)

История ввода хранится в `./.input_history` и сохраняется между запусками.

## 🧠 Модели с thinking (reasoning)

Для моделей, возвращающих `reasoning_content` (например, DeepSeek R1), укажите в конфиге:

```json
{
  "id": "deepseek-reasoner",
  "name": "DeepSeek R1",
  "supports_thinking": true,
  "context_window": 65536
}
```

Вывод будет выглядеть так:

```
💭 Размышляю...
   Нужно разобрать вопрос пользователя...
   Сначала проверю основные факты...

🤖 DeepSeek R1

Финальный ответ модели.

⏱ Токены: ↑250 ↓340 (💭120) │ 💰 0.05₽ │ ⏳ 5.3с
```

- Блок размышлений всегда выводится тусклым курсивом (plain text), независимо от markdown-режима.
- `thinking` сохраняется в файл сессии для отображения, но **не отправляется обратно в API**.

## 📂 История чатов и статистика

Все данные хранятся рядом с `main.py`:

| Путь | Назначение |
|---|---|
| `./config.json` | Конфигурация |
| `./.input_history` | Персистентная история ввода (для ↑/↓ и автодополнения) |
| `./usage_stats.json` | Накопительная статистика токенов и стоимости за всё время |
| `./history/` | Файлы сессий `YYYYMMDD_HHMMSS.json` |

### Автосохранение сессий

Сессия сохраняется после каждого ответа ассистента, а также при `/new`, `/exit`, Ctrl+C и Ctrl+D.

### Формат файла сессии

```json
{
  "session_id": "20231027_153000",
  "created_at": "2023-10-27T15:30:00",
  "default_model": "gpt-4o",
  "total_tokens": 37,
  "messages": [
    {
      "role": "user",
      "content": "Привет!",
      "timestamp": "2023-10-27T15:30:05"
    },
    {
      "role": "assistant",
      "content": "Здравствуйте! Чем могу помочь?",
      "model": "gpt-4o",
      "timestamp": "2023-10-27T15:30:07",
      "usage": { "prompt_tokens": 25, "completion_tokens": 12 }
    }
  ]
}
```

### Загрузка сессий

```
/history                  # таблица последних 20, выбрать по номеру
/history all              # все сессии
/history 20260527_104451  # по session_id
```

или из командной строки:

```bash
python main.py --history 20260527_104451
```

### Глобальная статистика

`/usage` показывает два блока:

- **Текущая сессия**: prompt/completion токены, стоимость, число запросов, средняя стоимость запроса.
- **За всё время** (из `usage_stats.json`): суммарные токены, суммарная стоимость, всего запросов.

| Ситуация | Поведение |
|---|---|
| **Ctrl+C** в ожидании ввода | Сохранить сессию → выход |
| **Ctrl+C** во время генерации | Прервать стрим, сохранить полученный фрагмент (`"interrupted": true`), показать статистику |

## ⚠️ Обработка ошибок

- **Сетевые ошибки / таймауты** — до 3 повторов с экспоненциальной задержкой (1с → 2с → 4с).
- **HTTP 401** — `Неверный API-ключ. Проверьте поле api_key в config.json` (без повтора).
- **HTTP 429** — учитывается `Retry-After`, автоматический повтор.
- **HTTP 400 (контекст)** — предложение удалить старые сообщения и повторить.
- **HTTP 500+** — повтор.

Все ошибки выводятся в **красной панели**, без traceback. Полный traceback — только с флагом `--debug` (в stderr).

## 🔧 Решение проблем (FAQ)

**Q: При запуске сразу выходит с «Конфиг создан…»**
A: Это нормально при первом запуске. Откройте `config.json`, впишите `api_key`, запустите снова.

**Q: `Ошибка конфига: отсутствует обязательное поле "api_key"`**
A: Проверьте, что в `config.json` присутствуют поля `api_key`, `api_base`, `default_model`.

**Q: `Ошибка парсинга config.json (строка N)`**
A: JSON повреждён (лишняя запятая, кавычки). Проверьте строку N или удалите файл — он будет пересоздан.

**Q: Стоимость показывается как `—`**
A: Текущая модель отсутствует в списке `models` либо у неё не заданы цены `input_price_per_1m_tokens_rub` /
`output_price_per_1m_tokens_rub`.

**Q: Ctrl+Enter не отправляет сообщение**
A: В некоторых терминалах Ctrl+Enter перехватывается. Большинство эмуляторов отправляют `Ctrl+J` — он забиндлен на отправку. Попробуйте
также обновить эмулятор терминала.

**Q: Не считаются reasoning-токены / нет блока «Размышляю…»**
A: Убедитесь, что у модели в конфиге указано `"supports_thinking": true`, и что API возвращает `reasoning_content`.

**Q: Кракозябры вместо кириллицы (Windows)**
A: Используйте Windows Terminal или установите UTF-8 (`chcp 65001`). Программа работает в UTF-8.

**Q: Где найти id моей сессии?**
A: Имя файла в каталоге `./history/` без расширения `.json` (например `20260527_104451`).
