# 🤖 Terminal AI Chat

Терминальный чат-клиент для LLM с OpenAI-совместимым API.
Поддерживает стриминг ответов, модели с reasoning (thinking), историю сессий,
многострочный ввод и автоматический расчёт стоимости запросов в рублях.

```
╭─────────────────────────────────────────╮
│  🤖 AI Chat  │  Модель: GPT-4o         │
│  Введите /help для списка команд        │
╰─────────────────────────────────────────╯

[GPT-4o] Вы › Привет! Что ты умеешь?

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 🤖 GPT-4o

 Я могу отвечать на вопросы, помогать с кодом,
 переводить тексты и многое другое.

 ⏱ Токены: ↑25 ↓42  │  💰 0.0290₽  │  ⏳ 1.4с
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 📋 Требования

- **Python 3.10+**
- Зависимости:
  - `openai >= 1.0`
  - `rich`
  - `prompt_toolkit`

---

## 🚀 Установка

```bash
pip install openai rich prompt_toolkit
```

Скачайте `chat.py` в удобную папку.

## ⚙️ Настройка

При первом запуске рядом с `chat.py` будет автоматически создан файл `config.json`
с шаблоном. Откройте его и подставьте свой API-ключ.

### Структура `config.json`

```json
{
  "api_key": "sk-...",
  "api_base": "https://api.openai.com/v1",
  "default_model": "gpt-4o",
  "system_prompt": "Ты полезный ассистент.",
  "generation": {
    "temperature": 0.7,
    "top_p": 1.0,
    "max_tokens": 4096
  },
  "models": [
    {
      "id": "gpt-4o",
      "name": "GPT-4o",
      "context_window": 128000,
      "input_price_per_1m_tokens_rub": 150.0,
      "output_price_per_1m_tokens_rub": 600.0
    },
    {
      "id": "deepseek-reasoner",
      "name": "DeepSeek R1",
      "context_window": 65536,
      "supports_thinking": true,
      "input_price_per_1m_tokens_rub": 3.0,
      "output_price_per_1m_tokens_rub": 15.0
    }
  ]
}
```

### Описание полей

| Поле | Обязательное | Описание |
|---|---|---|
| `api_key` | ✅ | API-ключ провайдера |
| `api_base` | ✅ | URL OpenAI-совместимого API |
| `default_model` | ✅ | `id` модели по умолчанию |
| `system_prompt` | ❌ | Системный промпт (по умолчанию: «Ты полезный ассистент.») |
| `generation.temperature` | ❌ | Температура (0.0–2.0, default 0.7) |
| `generation.top_p` | ❌ | Top-p sampling (default 1.0) |
| `generation.max_tokens` | ❌ | Лимит токенов ответа (default 4096) |
| `models[]` | ❌ | Список моделей для UI и расчёта стоимости |
| `models[].id` | ✅ (в каждой) | ID модели в API |
| `models[].name` | ❌ | Человекочитаемое имя (default = id) |
| `models[].context_window` | ❌ | Размер контекста в токенах (default 128000) |
| `models[].supports_thinking` | ❌ | Модель поддерживает reasoning (default false) |
| `models[].input_price_per_1m_tokens_rub` | ❌ | Цена за 1М входящих токенов (₽) |
| `models[].output_price_per_1m_tokens_rub` | ❌ | Цена за 1М исходящих токенов (₽) |

### Пример для DeepSeek

```json
{
  "api_key": "sk-...",
  "api_base": "https://api.deepseek.com/v1",
  "default_model": "deepseek-chat"
}
```

### Пример для локального LLM (Ollama / LM Studio)

```json
{
  "api_key": "not-needed",
  "api_base": "http://localhost:11434/v1",
  "default_model": "llama3.1"
}
```

## 💬 Использование

### Промпт ввода

```
[GPT-4o] Вы ›
```

В скобках отображается имя текущей модели. Вводите сообщение и нажимайте
**Alt+Enter** для отправки.

### Команды

| Команда | Описание |
|---|---|
| `/new` | Начать новый разговор (текущий сохранится) |
| `/history` | Список последних 20 сохранённых сессий |
| `/history all` | Все сохранённые сессии |
| `/model` | Интерактивный выбор модели из списка |
| `/model <имя\|№>` | Быстрое переключение (по имени, id или номеру) |
| `/file <путь>` | Отправить содержимое текстового файла |
| `/clear` | Очистить экран (контекст сохраняется) |
| `/usage` | Статистика по текущей сессии |
| `/help` | Справка |
| `/exit` | Выход |

### Примеры

```
[GPT-4o] Вы › /model 2
Модель переключена на DeepSeek R1

[DeepSeek R1] Вы › /file ./script.py
# (превью + подтверждение)

[DeepSeek R1] Вы › /usage
```

## ⌨️ Многострочный ввод

Чат поддерживает многострочный ввод:

- **Enter** — перевод строки (новая строка в текущем сообщении)
- **Alt+Enter** — отправить сообщение (на macOS: **⌥+Enter** или **Esc**, затем **Enter**)
- **↑ / ↓** — навигация по истории ввода
- **Ctrl+V / Shift+Insert** — корректная вставка многострочного текста из буфера

Это удобно для вставки кода, длинных вопросов, разметки и т. д.

## 🧠 Модели с thinking (reasoning)

Если в `config.json` у модели стоит `"supports_thinking": true`, то клиент
будет отображать «мысли» модели в реальном времени, отдельно от финального ответа.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 💭 Размышляю...
   Нужно разобрать задачу...
   Сначала проверю основные факты...

 🤖 DeepSeek R1

 Финальный ответ модели.

 ⏱ Токены: ↑250 ↓340 (💭120)  │  💰 0.0070₽  │  ⏳ 5.3с
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- `(💭120)` — количество reasoning-токенов (если API его сообщает)
- Reasoning сохраняется в истории, но **не отправляется** обратно в API
  при последующих запросах (только итоговый ответ).

Поддерживаются модели: **DeepSeek R1**, **o1-серия OpenAI** (через `reasoning_content`).

## 📚 История чатов

- Сессии сохраняются в папке `./history/` рядом с `chat.py`
- Имя файла: `YYYYMMDD_HHMMSS.json` (по моменту создания)
- Автосохранение: после каждого ответа ассистента, при `/new`, `/exit`, `Ctrl+C`
- Загрузить старую сессию: `/history` → ввести номер

### Формат файла

```json
{
  "session_id": "20231027_153000",
  "created_at": "2023-10-27T15:30:00",
  "default_model": "gpt-4o",
  "messages": [
    {"role": "system", "content": "...", "timestamp": "..."},
    {"role": "user", "content": "...", "timestamp": "..."},
    {
      "role": "assistant",
      "content": "...",
      "model": "gpt-4o",
      "thinking": "(если было)",
      "usage": {"prompt_tokens": 25, "completion_tokens": 12},
      "timestamp": "..."
    }
  ]
}
```

## 🛟 Решение проблем

### «Неверный API-ключ»
Проверьте поле `api_key` в `config.json`. Убедитесь, что ключ не истёк,
и что вы используете правильный `api_base` для вашего провайдера.

### «Превышен контекст модели»
Используйте `/new` для нового разговора или согласитесь на автоматическое
удаление старых сообщений.

### Модель не показывает стоимость («—»)
Модель отсутствует в списке `models` в `config.json` или не указаны цены.
Добавьте её или укажите `input_price_per_1m_tokens_rub` / `output_price_per_1m_tokens_rub`.

### Стриминг отображается некорректно (артефакты)
Используйте современный терминал с поддержкой ANSI:
- **Windows**: Windows Terminal, PowerShell 7+
- **macOS**: iTerm2, встроенный Terminal.app
- **Linux**: gnome-terminal, kitty, alacritty

### Alt+Enter не работает
На некоторых терминалах нужно нажать **Esc**, затем **Enter** (это та же
комбинация). На macOS убедитесь, что у вас включена опция «Use Option as Meta key»
в настройках терминала.

### Кракозябры вместо кириллицы (Windows)
Запустите перед стартом:
```cmd
chcp 65001
```
или используйте Windows Terminal — он использует UTF-8 по умолчанию.

### Ошибка `Ошибка конфига: укажите реальный api_key`
Замените `"sk-YOUR-KEY-HERE"` в `config.json` на реальный ключ.
